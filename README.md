A modern, responsive developer portfolio website showcasing my projects, technical skills, experience, certifications, and journey as a **Full Stack & Mobile Application Developer**.

## 💻 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

Navigate into the project:

```bash
cd YOUR_REPOSITORY
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:3000
```
